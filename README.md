# Frontend Store

Este proyecto es una **tienda en línea** estática creada utilizando únicamente **HTML5** y **CSS3**. El objetivo del proyecto es mostrar el diseño y la estructura de una tienda en línea que incluye 
páginas para productos y una pagina principal.

## Descripción

El proyecto **Frontend Store** simula la interfaz de una tienda en línea, donde los usuarios pueden visualizar productos, ver detalles y navegar a través de diferentes secciones como el carrito de 
compras y la página de contacto. Se ha implementado un diseño responsive para asegurar que la página sea accesible desde dispositivos móviles y pantallas más grandes.

### Características principales

- Página de inicio con una lista de productos destacados.
- Página individual para cada producto con más detalles.
- Página acerca de nosotros.
- Diseño responsive que se adapta a diferentes tamaños de pantalla.
  
## Tecnologías utilizadas

- **HTML5**: Para la estructura y el contenido del sitio.
- **CSS3**: Para el diseño visual, incluyendo layout, colores, fuentes y diseño responsive.

## Estructura del proyecto

El proyecto está dividido en los siguientes archivos:

- **index.html**: Página principal con los productos destacados.
- **productos.html**: Página donde se listan todos los productos disponibles.
- **nosotros.html**: Página que muestra información como ejemplo de una pestaña de nosotros.
- **styles.css**: Archivo de estilos CSS que contiene el diseño y las reglas de estilo.
- **img/**: Carpeta que contiene las imágenes de los productos y otros elementos visuales.
